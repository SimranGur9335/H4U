Raw scores describe the coping effort for each of the eight types of coping. High raw scores indicate that the person often used the behaviors described by that scale in coping with the stressful event.
Relative scores describe the proportion of effort represented for each type of coping and are expressed as a percentage ranging from 0 to 100.
1.	Calculate the average response per scale by dividing the total raw score by the number of items in the scale. Example in the supplied material: if the raw score for Confrontive Coping is 15, the average response is 2.5 because there are 6 items.
2.	Sum the average responses per scale across all eight scales.
3.	Divide the average score for each scale by the sum of the averages for all 8 scales. This value is the relative score for the scale.

AI IMPLEMENTATION — COMMON DATA & SCORING SCHEMA
For each assessment, retain the original item-level responses and store calculated scores as derived fields. This allows the AI's result to be audited and re-scored when the scoring version changes.
Field	Purpose
test_id / test_name	Identify the instrument
item_responses	Original response to every administered item
scoring_version	Version/source of scoring rules and norms
subscale_or_dimension_raw_scores	Calculated raw score for every domain
standard_scores	z-scores or other standardized scores only where source-supported
grade / category	Source-defined categorical result
interpretation	Human-readable result linked to source norms
review_status	Flag incomplete/ambiguous scoring for human review
